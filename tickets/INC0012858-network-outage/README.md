# INC0012858 — Network Outage

## Ticket Summary

- Priority: Critical
- Category: Network connectivity
- Affected area: Third floor and conference rooms on the second floor
- Business impact: Multiple departments cannot work, and Customer Service cannot access the CRM
- Status: Investigating

## Initial Actions

1. Reviewed the ticket and confirmed that the problem affects many users on different floors.
2. Informed the user that I started investigating the network outage.
3. Opened the available tools to check the network equipment.
   
## Investigation Findings

1. Checked the Server Room overview.
2. Confirmed that 12 of 13 network nodes were up.
3. Confirmed that the ISP, core router, and firewall were online.
4. Found an error on the Floor 3 Switch in Server Room B.
5. Reviewed the network topology before taking action.
6. Did not reboot the switch because I needed to check the correct procedure first.
