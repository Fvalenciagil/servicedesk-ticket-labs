# INC0012858 — Network Outage

## Ticket Summary

- Priority: Critical
- Category: Network connectivity
- Affected area: Third floor, including the conference rooms
- Business impact: Multiple departments were unable to work, and Customer Service could not access the CRM
- Status: Resolved

## Initial Actions

1. Reviewed the ticket and confirmed that the problem affects many users on the third floor.
2. Informed the user that I started investigating the network outage.
3. Opened the available tools to check the network equipment.
   
## Investigation Findings

1. Checked the Server Room overview.
2. Confirmed that 12 of 13 network nodes were up.
3. Confirmed that the ISP, core router, and firewall were online.
4. Found an error on the Floor 3 Switch in Server Room B.
5. Reviewed the network topology before taking action.
6. Confirmed that the Floor 3 Switch was the affected network device.

## Resolution

1. Rebooted the Floor 3 Switch using the Server Room tool.
2. Confirmed that the switch returned to online status.
3. Confirmed that all 13 network nodes were up.
4. Asked the user to test the internet, websites, and CRM.
5. The user confirmed that all services were working again.

The cause of the switch error was not confirmed.
