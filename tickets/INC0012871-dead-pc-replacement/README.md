# INC0012871 — Dead PC Replacement

## Ticket Summary

- Priority: Critical
- Category: Hardware
- Affected user: Customer Support agent
- Business impact: The user could not take calls because the desktop had no power
- Status: Resolved

## Initial Actions

1. Reviewed the ticket and contacted the user.
2. Confirmed that the desktop had no lights, fan, or beep.
3. Asked the user to check the monitor, power strip, UPS, and wall outlet.
4. Confirmed that a replacement desktop was needed.

## Investigation Findings

- Desktop SD1006 had no power.
- The monitor and power strip also showed no power.
- The exact cause of the failure was not confirmed.
- Customer Support requires Server Imaging for replacement computers.

## Resolution

1. Verified that asset tag SD2022 was available.
2. Prepared desktop SD2022 using Server Imaging.
3. Registered the computer in Asset Management.
4. Shipped the replacement with Rush Priority.
5. Included a return label for the damaged computer.
6. Confirmed that the user could sign in and access the softphone and call queue.
7. Verified that SD2022 was assigned and showed as Deployed.

## User Communication

The user confirmed the delivery address through Team Chat. I informed the user that the replacement desktop was ready for shipping.
